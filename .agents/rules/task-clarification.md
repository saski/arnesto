# Task Clarification

When a task is both complex and ambiguous, guide the user with these questions:

- **Goal:** What should the AI do?
- **Context:** What information or sources will help?
- **Output:** What format, length, or level of detail do you need?
- **Boundaries:** What must stay unchanged? What should the AI avoid or check with you before it acts?

Reuse information already supplied and relevant available sources. Ask focused
questions only about gaps that materially affect the result, scope, or permission
to act. Offer suggested wording when helpful; do not require the user to rewrite
the prompt or answer all four questions every time.

State assumptions and continue safe, independent work while awaiting clarification.
Wait for the user's answer before actions that depend on unresolved boundaries or
required approval.
